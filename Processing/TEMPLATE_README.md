# Notes about Templates

- Naming structure follows `<Recording Device>_<HMD>-<OS Version>`.
    - e.g. `mqp_mqp-v2.1.1034`:
        - Recorded from a Meta Quest Pro (MQP) using its in-built recording system.
        - The HMD being calibrated is a MQP as well - specifically, OS version 12.1.1034.
- Templates should contain the general structure:
    - `calibration.json`: The calibration file that is generated by `calibrate.py` and used in either `estimate.py` or `rescale.py`. Use this to transform coordinates from VR screen space to video/frame space.
    - `calibration.csv`: The original calibration targets used in the Unity calibration scene packaged with this repository (if you are viewing this from an external database and aren't looking at this from its original Github repository, refer to the original repository).
    - `cube.csv`: A test case that can be used to debug the accuracy of `calibration.json`, using `estimate.py`.
    - `capture.mp4`: Video recording of both the calibration session (to be referenced in `calibrate.py`) and a validation session with a blue cube (to be referenced in `estimate.py` in conjunction with `cube.csv`).
    - `estimations/`: The output of `estimate.py` using `cube.csv`.
    - `calibrations/`: The output of `calibrate.py` using `calibration.csv` and `capture.mp4`.
